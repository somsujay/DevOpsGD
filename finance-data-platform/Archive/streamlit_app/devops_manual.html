Key Rotation

# Generate new key pair
openssl genrsa 2048 | openssl pkcs8 -topk8 -inform PEM -out new_key.p8 -nocrypt
openssl rsa -in new_key.p8 -pubout -out new_key.pub

# Register in Snowflake (zero-downtime rotation)
ALTER USER SOMSUJAY SET RSA_PUBLIC_KEY_2='<new-public-key>';

# After CI validates, swap keys:
ALTER USER SOMSUJAY SET RSA_PUBLIC_KEY='<new-public-key>';
ALTER USER SOMSUJAY UNSET RSA_PUBLIC_KEY_2;

5. Deployment Procedures

Standard Deployment

# Deploy to dev (local)
bash scripts/deploy_schemachange.sh --env=dev

# Deploy to QA
bash scripts/deploy_schemachange.sh --env=qa

# Dry-run (no changes)
bash scripts/deploy_schemachange.sh --env=prod --dry-run

Standard Release (QA → PreProd → Prod)

# 1. Create release branch
git checkout develop && git pull
git checkout -b release/v1.3.0

# 2. Push triggers deploy-qa.yml
git push -u origin release/v1.3.0

# 3. Merge to main (triggers deploy-preprod.yml)
gh pr create --base main --title "Release v1.3.0"
gh pr merge <pr-number> --merge

# 4. Tag for production (triggers deploy-prod.yml)
git checkout main && git pull
git tag v1.3.0
git push origin v1.3.0

9. Incident Response

LevelDefinitionResponse Time
SEV1Production data loss or corruptionImmediate
SEV2Production pipeline broken30 minutes
SEV3Non-prod broken or degraded4 hours
SEV4Cosmetic or documentationNext sprint

SEV1/SEV2 Playbook

1. ASSESS    - Check GitHub Actions logs + Snowflake query history
2. CONTAIN   - Suspend tasks: ALTER TASK RAW_DEV.TASK_LOAD_* SUSPEND;
3. ROLLBACK  - gh workflow run deploy-prod.yml -f action=rollback -f rollback_version=<tag>
4. VALIDATE  - bash scripts/run_smoke_tests.sh --env=prod
5. COMMUNICATE - Post incident summary, create follow-up ticket

13. Disaster Recovery

Snowflake Time Travel

-- Query data as of 1 hour ago
SELECT * FROM RAW_DEV.T_CUSTOMER AT(OFFSET => -3600);

-- Restore a dropped table
UNDROP TABLE CLEAN_DEV.DIMCUSTOMER;

-- Clone from point in time
CREATE TABLE CLEAN_DEV.DIMCUSTOMER_BACKUP CLONE CLEAN_DEV.DIMCUSTOMER
  AT(TIMESTAMP => '2026-07-15 10:00:00'::TIMESTAMP);

Full Environment Recovery

# 1. Recreate database
snow sql -c MY_TRIAL_ACCOUNT -q "CREATE DATABASE IF NOT EXISTS FINANCE_CORE_PROD;"

# 2. Redeploy all migrations
git checkout $(git describe --tags --abbrev=0)
bash scripts/deploy_schemachange.sh --env=prod

# 3. Reload data
bash scripts/run_historical.sh
bash scripts/run_incremental.sh
